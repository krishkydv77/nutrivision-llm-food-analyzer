# NutriVision LLM – AI Food Nutrition Analyzer

NutriVision LLM is an AI-powered food analysis application that uses **Computer Vision and Large Language Models (LLMs)** to analyze food images and provide estimated nutritional information, a health verdict, and personalized health tips.

The application is built with **FastAPI**, **Google Gemini**, **PIL**, **Jinja2**, and **Docker**, and can be deployed on cloud infrastructure such as **AWS EC2**.

## Features

* Upload a food image through a web interface
* AI-based food identification and description
* Estimated nutritional information
* Calories estimation
* Protein, carbohydrates, fats, and fiber estimation
* Key vitamins and minerals
* Healthy / Unhealthy health verdict
* AI-generated health recommendations
* Markdown-formatted nutrition table
* FastAPI-based backend
* HTML/Jinja2 frontend
* Gemini LLM integration
* Environment-variable based API key configuration
* Docker-ready deployment

## How It Works

The application follows this workflow:

```text
User Uploads Food Image
          ↓
       FastAPI
          ↓
     Image Processing
          ↓
    Google Gemini LLM
          ↓

          ↓

 │ Food Identification     │

          ↓

```

## AI Analysis Output

NutriVision LLM generates four major sections:

### 1. Food Name

Identifies the food item and provides a brief description.

### 2. Nutritional Information

The application requests estimated values for:

| Nutrient          | Description                    |
| ----------------- | ------------------------------ |
| Calories          | Estimated calorie content      |
| Protein           | Estimated protein content      |
| Carbohydrates     | Estimated carbohydrate content |
| Fats              | Estimated fat content          |
| Fiber             | Estimated dietary fiber        |
| Vitamins/Minerals | Important micronutrients       |

### 3. Health Verdict

The LLM provides a simple health classification:

```text
Healthy
```

or

```text
Unhealthy
```

along with the reasons behind the verdict.

### 4. Health Tips

The model provides suggestions for making the meal more balanced or healthier.

## LLM Integration

The project uses Google's Gemini API through the Python GenAI SDK.

Example:

```python
from google import genai

client = genai.Client(api_key=api_key)

response = client.models.generate_content(
    model="YOUR_AVAILABLE_GEMINI_MODEL",
    contents=[image, prompt]
)
```

The food image and analysis prompt are provided to the multimodal model, which generates the nutritional analysis.

> **Note:** Gemini model availability can change over time. Use a model currently available to your API key/project instead of hard-coding an unavailable model identifier.

## Important Disclaimer

**NutriVision LLM provides estimated nutritional information generated by an AI model.**

The nutritional values are **not laboratory-tested measurements** and should not be considered medically accurate.

Actual nutrition can vary significantly depending on:

* Portion size
* Ingredients
* Cooking method
* Recipe
* Brand
* Preparation method
* Food quality

The application is intended for **educational, demonstration, and informational purposes only** and should not be used as a substitute for professional medical or dietary advice.

## Data Transparency

This project focuses on demonstrating an **AI/LLM-based food analysis workflow**.

Where nutritional values are estimated or generated rather than obtained from verified laboratory measurements, they should be treated as **approximate estimates**.

The project does not claim that AI-generated nutrition values are equivalent to measurements from certified nutritional databases or laboratory analysis.
